# TAREA-2

Portal educativo interactivo sobre arquitectura de computadores, redes de comunicaciones e investigación de ciberdelitos.

## Tecnologías

- HTML5 semántico
- CSS3 responsive
- JavaScript Vanilla
- GitHub Codespaces para el desarrollo
- GitHub Pages para el despliegue público

## Desarrollo local

Desde GitHub Codespaces, ejecuta:

```bash
python3 -m http.server 4173
```

Después abre `http://localhost:4173`.

## Despliegue

El workflow `.github/workflows/pages.yml` publica automáticamente el contenido de la rama `main` en GitHub Pages después de cada push. La URL pública del proyecto es:

https://dariobj69.github.io/TAREA-2/
